## 已实现

- [x] 快照携带每位玩家的位置、本轮下注、本手累计投入和最后动作。
- [x] 当前用户座位旋转到屏幕下方，其他座位保持顺时针顺序。
- [x] 玩家与底池之间显示本轮下注筹码。
- [x] 服务端为每次行动生成统一截止时间。
- [x] 超时后可过牌则自动过牌，否则自动弃牌。
- [x] 所有客户端使用服务端时间校准显示相同倒计时。
- [x] 提供 1/4 池、1/3 池、1/2 池、2/3 池、满池、1.2 倍超池和全下。
- [x] 提供最小/最大范围内的滑块和数字输入。
- [x] 明确使用“下注至/加注至”语义，并显示本次还需投入。
- [x] 动作请求等待服务端确认期间锁定按钮，避免重复提交。
- [x] 摊牌只公开未弃牌玩家底牌和牌型。
- [x] 弃牌结束不公开其他玩家底牌。
- [x] 显示主池、边池、赢家和获得筹码。
- [x] 当时将本人手牌移至牌桌与操作栏之间；`v0.1.1` 进一步移入本人玩家框。
- [x] 七档合法快捷额度在底栏直接展示，自定义按钮单独打开滑块和数字输入。
- [x] 自定义下注窗口持续显示服务端倒计时。
- [x] 每手每位参赛玩家拥有两张 30 秒加时卡。
- [x] 当前玩家可以主动使用加时卡，超时时会优先自动消耗。
- [x] 加时卡耗尽后才执行自动过牌或自动弃牌。
- [x] 任一阶段未弃牌玩家只剩两人时，后续每次行动基础时间改为 60 秒。

## 待实机验收

- [ ] 2、3、6、10 人桌位置显示与行动顺序正确。
- [ ] 三台设备倒计时误差不超过 1 秒。
- [ ] 七档推荐额度、滑块和数字输入均能提交合法动作。
- [ ] 非法额度、过期动作和重复点击不会重复扣除筹码。
- [ ] 超时自动动作后所有设备收到相同快照。
- [ ] 摊牌、弃牌获胜、平分底池和多边池显示正确。
- [ ] 断线重连后位置、下注额、剩余时间和本人底牌恢复正确。
- [ ] 主动连续使用两张加时卡时，截止时间累计增加 60 秒。
- [ ] 不主动使用时，两次超时依次自动消耗两张加时卡，第三次超时才自动行动。
- [ ] 三人及以上局面变为两人后，下一位玩家获得 60 秒基础行动时间。
