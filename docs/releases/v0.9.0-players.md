# 好友德州 0.9.0 更新说明

所有平台均需更新（Web 端刷新即可）。

## 新增：AI 复盘

- 管理员给你开通后，牌局回放页会多一个「AI 复盘」按钮。点一下，AI 会像教练一样点评你在这一手里的每一次行动：打得好、合理、有争议还是失误，为什么，以及这一步的最佳打法。
- 复盘开头列出这一手的概况：几人桌、盲注、你的位置和底牌、每家的码量。每一步还会列出当时的底池、要跟多少、跟注至少需要多少胜率、你的牌力，以及 AI 估算的胜率和期望收益（这一步你的打法与最佳打法各赚或亏多少个大盲）。
- 分析一般需要半分钟到两分钟，期间可以继续看回放，结果出来会自动显示。点某一条点评可以直接跳到回放里的那一步。
- 点评还会结合对手在你们一起打过的牌局里的打法习惯。
- 同一手只需分析一次，之后随时可以再看。
- 发给 AI 的只有位置、筹码、牌、行动和输赢，不包含任何人的昵称；别人没亮过的牌也不会发出去。同桌有人发起复盘时，你在那一手里的位置、筹码、行动、摊牌亮出的牌和输赢，以及你们一起打过的牌局里你的打法统计，也会一起发出（同样不带昵称）。详见「隐私说明」。
