# 好友德州 v0.6.1

修复一个**会让玩家真实丢失筹码**的服务端缺陷。服务端必须更新；客户端只多了一条提示文案；**没有新的数据库迁移**。

## 事故经过

一位房主在某一手弃牌后中途离开房间，过了几分钟重新进入同一房间，打了一阵又离开。事后他的钱包少了 18770 筹码：第一次离开时桌上的 8530 没有退回，最后一次离开时桌上的 10240 也没有退回。同桌其他人的钱没有少，但有两手牌没有写进牌谱。

## 根因

**一、弃牌中途离开时，成员记录被提前删除。** 弃牌者的筹码要等本手结算才定得下来，所以退还本来就设计成推迟到结算之后。但「离开房间」这一步没有推迟：成员记录当场删除。在 PostgreSQL 里，桌上筹码就记在 `room_members.table_chips` 上——那一行一删，筹码连同记录一起消失，不留任何流水。随后本手结算又因为找不到这一行而整手回滚，其他人的输赢记不上账，牌谱也没写。

内存版的钱包仓储把桌上余额另存一处，删成员不影响它，所以这条路径的单元测试一直是绿的。这是「内存仓储拦不住」的又一例，而且是代价最高的一例。

**二、离桌退还的幂等编号按「房间 + 用户」固定。** 同一个人在同一房间第二次离开时，编号与第一次相同，退还被当成重复请求直接跳过；随后成员记录一删，桌上筹码就没了。

**三、（排查中发现）牌谱只取结算后的引擎座位。** 引擎在结算的同时就移除了待离开的玩家。他若在这一手下过注（比如盲注位），牌谱里少了他这一行，整手输赢对不上账，牌谱写入失败，结算跟着报错，此后每一手都结算不了。事故里那位房主弃牌时恰好一个筹码都没下，才没有触发。

## 修复

- **弃牌中途离开只登记「待离开」**，成员记录保留到本手结算；结算把这一手之后的筹码写进去，再退回钱包、移出房间。该状态随牌桌状态持久化，崩溃恢复后仍然有效。
- **退还编号按每一次入座区分**：编号带上入座时间，入座时间由房间服务保证在进程内严格递增（不依赖时钟粒度——Windows 上 `time.Now` 约半毫秒才跳一次），取微秒以便经 PostgreSQL 往返后不变。同一次入座内重试只退一次，重新入座则一定是新的编号。
- **牌谱补上离开者**：离开时记下他的座位与底牌，结算时用它补齐牌谱。
- **退还挪到牌谱写入之后**，退还失败不再连累这一手的牌谱。
- **落盘中途失败会补做**：下一次有人准备时整段重做。重做时筹码不会再写一遍——两次之间可能有人补码，拿旧结算覆盖会把补进来的筹码盖掉。

### 待离开期间玩家看到什么

- 对他本人表现为已经离开：重启应用停在大厅。
- 创建房间或加入别的房间：提示「你刚离开的那一手还没打完」（新错误码 `leave_pending`，HTTP 409）。
- 输入原房间码加入：等于撤销离开，回到原座位，筹码不变、不重复扣带入。

## 升级须知

- **只需更新服务端并重启**，无迁移。客户端更新后才会显示 `leave_pending` 的中文提示，不更新也不影响使用。所有人装好后，最低客户端版本可填 `6001`。
- **已经丢失的筹码不会自动补回。** 用更新手册里的方式连上数据库，按用户与房间查 `bankroll_entries`：带入之后没有对应 `cash_out` 的那一段，其最后一条 `hand_settlement` 的 `table_balance_after` 就是应补的数额（若离开的那一手下过注，再减去那部分），由管理员在后台补进钱包。
- 修复之前的临时规避仍然成立，但更新后不再需要：同一房间只离开一次、且只在两手之间离开。

## 测试

- 新增 9 个牌桌管理层用例：同一房间三次进出每次都退还且战绩延续、退还编号规则、弃牌离开后结算再进入、结算前回到原房间撤销离开、离开者下过注时结算守恒、牌谱含离开者、待离开状态跨重启保留、退还失败后补做、补做不覆盖期间的补码。
- 新增 HTTP 层用例覆盖待离开期间的三种表现。
- **新增 PostgreSQL 集成用例**按事故流程走一遍，并特意让离开者下过注，再重新进入、第二次离开；核对成员记录、流水条数、牌谱与筹码守恒。这条用例只能在真实库上运行。
- 随机进出的性质测试此前几乎开不起牌局（六个人靠逐个随机准备很难同时就绪），「牌局进行中」的路径等于没测。现在加入「全员准备」操作，五个种子共 2000 步里走到 54 次弃牌后中途离开，每一步都校验筹码守恒与全员快照可生成。
- 顺带加固一条对机器速度敏感的 WebSocket 用例：它取「下一条翻牌前快照」，缓冲里若还躺着一条旧快照就会读错，慢机器上约六次失败一次。

## 已知边界

- 待离开者在本手结算前仍占着座位与成员名额；房主的移交也推迟到结算之后。
- 若服务端崩溃且那一手没能恢复，「待离开」标记随之丢失，他会变回普通成员（筹码完好），需要本人再点一次离开或由房主移出，否则他不会准备、下一手开不了。
- 离开后大厅显示的钱包数字要到下一次刷新才会加上退还的筹码（此前也是如此）。
