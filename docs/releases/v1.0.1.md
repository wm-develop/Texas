# 好友德州 v1.0.1

在 1.0.0 基础上的小版本：牌局记录标出已有 AI 复盘的手、修正 Windows 上汉字字形不对，AI 复盘的措辞改用 limp。**服务端与客户端都要更新**，没有数据库迁移，也没有新的环境变量。

## 玩家看到什么

- **牌局记录里标出分析过的手**：本人已有 AI 复盘结果的手，在底牌左边显示金色的「AI 已复盘」；窄屏（手机浏览器竖屏）上只显示图标。在回放里分析完退回牌局记录，不用刷新就会带上标识。
- **Windows 客户端的汉字写法正常了**：此前不少字（例如「骨」「直」「误」）按日文字形显示，现在与其他平台一致。系统对话框、输入框菜单里的文字（返回、粘贴等）也变成了中文。
- **AI 复盘把翻前平跟大盲写成 limp**，不再用「跛入」这类不常见的译名。已有的复盘结果仍然能看，面板上会出现「用新版重新分析」。

## 实现要点

- **复盘标识**：`GET /v1/hands/recent` 的响应多了 `reviewedHandIds`，是这一页里本人已有复盘结果（任意版本的提示词）的手号。排队中、分析中、失败的不算；现在用不了复盘（没配置模型、总开关关着、不在名单里）时不给，因为结果打不开。一个都没有时省略这个字段；查询失败只写服务端日志，不影响牌局记录。只查当前这一页，走 `hand_reviews` 已有的唯一索引。回放页拿到结果时通知牌局记录，所以返回后立即显示。
- **Windows 字形**：Flutter 按界面语言（`Localizations` 的 locale）给汉字挑后备字体。此前应用没有设置语言，默认是英文界面，Windows 上挑到了日文字体；Web 由浏览器挑字体，所以没有这个问题。现在通过 Flutter SDK 自带的 `flutter_localizations` 把界面语言固定为简体中文（`zh-Hans-CN`），汉字落到微软雅黑上；按钮等自定义了文字样式的地方也一样生效。已在 Windows 上实际构建对比过英文与中文两种界面的渲染。
- **提示词 v2**：只加了一句措辞要求（翻前平跟写作 limp、这样入池的人写作 limper、针对他们的加注写作 iso-raise），发给模型的数据不变，隐私说明不用改。按约定升了 `PromptVersion`，所以已有结果都标为旧版。

## 接口与协议

- `GET /v1/hands/recent` 新增可选字段 `reviewedHandIds`。旧客户端忽略它；新客户端连旧服务端时不显示标识。详见 `docs/WEBSOCKET_PROTOCOL_V1.md` 7.8。

## 升级须知

1. 更新服务端并重启。没有迁移，环境变量不变。
2. 分发 1.0.1 客户端（Web 端重新构建）。所有人装好后可以把「最低客户端版本」填成 `1000001`；这一版没有必须强制升级的原因，不填也可以。
3. 提示词升了版本：已有复盘显示为旧版，玩家点「用新版重新分析」才会重新调用模型并占一次次数，不会自动重跑。

## 测试

- 服务端：复盘仓储的 `DoneHands` 只算已完成的、旧版也算、只看本人、空列表返回空（内存实现与真实 Postgres 共用同一套检查，Postgres 在 CI 上跑）；服务层在排队中、收回权限、关掉总开关时都不标；接口端到端：排队中不标，分析完后本人的牌局记录里有、同一手的对手没有。
- 客户端：解析 `reviewedHandIds`；只在有结果的手上显示标识；在回放里看到结果后返回列表立即显示；桌面、手机横屏（含 115%、130% 系统字号）与窄屏下的标识渲染检查。
- 用真实 DeepSeek 复盘了两手含有 limp 的牌，输出用的是 limp。
