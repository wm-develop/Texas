# 好友德州 0.6.0 更新说明

所有平台均需更新（Web 端刷新即可）。

## 新增

- 设置里新增「换座与看牌申请」：可以关掉「允许别人向我申请换座」和「允许别人申请私下看我的牌」。关掉后对方的申请会被直接拒绝，你不会再被打扰。设置只在当前房间有效，离开房间后恢复为允许。
- 拒绝换座时可以选「不再接受此人的换座申请」，在你离开房间前，这个人都不能再向你申请。
- 拒绝看牌时可以选「本手不再接受此人」或「本手不再接受任何人」，下一手自动恢复。
- 对方同意给你看牌后，本手不能再向同一个人申请。
- 申请被拒绝时会告诉你是哪一种拒绝（这次拒绝、不再接受你、不接受任何人、对方关掉了申请），而且只有你自己看得到，同桌其他人不知道谁拒绝了谁。

## 修复

- 本房间战绩：自己已经弃牌时，这一手已经投进底池的筹码现在计为已输，不再虚高。
