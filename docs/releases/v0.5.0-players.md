# 好友德州 0.5.0 更新说明

所有平台均需更新（Web 端刷新即可）。

## 新增

- 服务器意外重启后，正在打的那一手不再作废，能接着打完。
- 手机、平板上被系统清理掉后重新打开，不用再输账号密码，直接回到原来那一桌。电脑浏览器上仍需重新登录（浏览器常常是公用的）。
- 「最近牌局」里能看到每一手的行动过程，例如「翻牌前：我 加注到 60，对手 跟注 40」。对手盖着牌结束时显示「未亮牌」。

## 优化

- 鸿蒙手机上的设置弹窗能滚到最后一项了，房主能看到「房间管理」。
- 花色的颜色在所有平台一致，玩家框里的「10」不再错位。
- 房间管理里的看牌费输入框改成整行带标签的样式。
