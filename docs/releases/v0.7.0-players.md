# 好友德州 0.7.0 更新说明

所有平台均需更新（Web 端刷新即可）。

## 新增：抽水

- 管理员可以给房间开启抽水：每手从底池里按比例抽走一小部分筹码（可设封顶），发出翻牌的手还可以再加抽一笔固定筹码（不超过一个大盲）。默认不抽，是否开启、抽多少由管理员按房间决定。
- **规则一变，房间文字聊天里会出现一条「系统公告」**，写明比例、封顶和加抽数额，并且从下一手才开始生效，正在打的这一手不受影响。
- 牌桌左上的房间信息里会一直显示当前的抽水规则；输入房间码准备加入时，带入窗口里也会写明，进房间之前就能知道。
- **每手结算时会写明「本手抽水 X」**，你分到的筹码已经扣过它；「最近牌局」里也能看到每一手抽了多少。
- 没人跟注而退回给你的筹码不算进底池，不会被抽。底池很小（不足两个大盲）时不加抽。有边池时抽水按各个池的大小分摊，短码全下的人只承担主池那一份。看牌费不抽水。
- 抽走的筹码进入管理员账户。管理员账号不能上桌打牌。
