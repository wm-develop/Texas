# 好友德州 v0.4.3

仅客户端改动，服务端与数据库无变化，已部署的 v0.4.2 服务端无需更新。四端客户端重新构建后，管理员把最低客户端版本设为 4003。

## 修复

- **鸿蒙手机上设置弹窗滚不到最后一项**：房主看不到「房间管理」，管理员看不到「打开服务器管理」。内容区此前按「屏幕高度 × 70%」限高，上游 Flutter 会把它压到弹窗真实剩余空间，OpenHarmony 那版不会，于是滚动范围按错误的高度算，最后一项永远落在被裁掉的那一截里。新增 `DialogScrollArea` 按屏幕真实可用空间计算高度，设置、房间管理、房间名单三个弹窗统一使用。
- **玩家框小牌「10」错位**：一行文字放不下时折成靠左两行。小牌改为一律「点数在上、花色在下」居中。
- **花色符号没有跟着四色染色**：♠♥♦♣ 在 Android / HarmonyOS 上被系统彩色 emoji 字体接管，文字颜色对它不起作用。花色改为自绘图形（`SuitGlyph`），公共牌与玩家框同一套，四端一致。
- 快照尚未到达时房主判断退回房间信息里的房主，避免「房间管理」入口短暂缺失。

## 调整

- 黑桃图形的底座缩短、心形部分放大。
- 房间管理里的看牌费输入框改为与补码弹窗同款的整行带标签输入。

## 测试

新增弹窗内容区高度公式、矮屏滚到底可点到「房间管理」、四色花色图形、小牌居中等用例；客户端 300 项、服务端全量通过。
