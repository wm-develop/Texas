# 好友德州 v0.1.1

v0.1.1 主要重构手机端牌桌布局，并完善摊牌展示、牌桌图层、HarmonyOS 数字输入和全面屏挖孔适配。

## 发布方式

本 Release **不会直接附带 Web、Windows、Android、HarmonyOS 或 iOS 安装包**，仅发布 Git 标签对应的源码快照。

客户端需要写入自建游戏服务地址，语音需要部署者自己的腾讯云 TRTC 配置，Android 与 HarmonyOS 正式分发还涉及各自的平台签名，因此各平台产物应由部署者根据自己的环境构建、签名和测试。

从空服务器开始部署，请参阅[自建部署指南](https://github.com/wm-develop/Texas/blob/v0.1.1/docs/SELF_HOSTING_GUIDE.md)。已有部署的版本升级流程请参阅[生产环境更新手册](https://github.com/wm-develop/Texas/blob/v0.1.1/docs/PRODUCTION_UPDATE_GUIDE.md)。

## 手机端牌桌重构

- 重构 Android 和 HarmonyOS 手机横屏牌桌，扩大牌桌可用空间。
- 房间信息、连接状态和语音控制调整至牌桌侧边，减少顶部空间占用。
- 移除独立的“你的手牌”区域，手牌直接显示在自己的玩家框内。
- 玩家框集中展示手牌、剩余筹码、位置、房主状态和加时卡等必要信息。
- 2–10 人座位沿牌桌周边重新排列，避免玩家框长期侵入公共牌区域。
- 公共牌、玩家框、本轮下注筹码和好友互动动画采用独立图层：
  - 玩家框显示在公共牌背景之上，置顶范围严格限制在玩家框自身。
  - 本轮下注筹码显示在玩家框之上。
  - 赞赏和嘲讽气泡位于最高层，播放时不会被玩家框或公共牌遮挡。

## 摊牌展示优化

- 摊牌不再使用牌桌中央附近的独立浮层。
- 结算时直接在对应玩家框中展示两张手牌、中文牌型、赢家标志和赢取筹码。
- 下一手开始后自动恢复玩家框的常规信息。
- 修复“发两次”时，对方摊牌可能被两块公共牌区域遮挡的问题。

## HarmonyOS 输入优化

- 重做横屏数字输入面板，0–9、清空、退格和确定按钮一次性完整显示。
- 不再需要在无法正常滚动的数字区域中寻找被遮挡的按键。
- 改善房间号、大小盲、带入量、补码和自定义下注的输入体验。

## 全面屏与挖孔屏适配

- Android 通过原生 `WindowInsets.displayCutout` 获取真实挖孔和瀑布屏安全区域。
- HarmonyOS 通过原生 `Window.getWindowAvoidArea(AvoidAreaType.TYPE_CUTOUT)` 获取真实挖孔避让区。
- 原生安全区域通过 MethodChannel 传递给 Flutter，只补充尚未由 `SafeArea` 消费的部分，避免重复留白。
- 横屏方向、窗口尺寸或应用前后台状态变化时会重新读取安全区域。
- 不再使用固定像素边距猜测摄像头位置。

## 升级说明

- 本次没有数据库结构变化，不需要执行数据库迁移。
- 本次没有游戏服务协议或服务端逻辑变化，不需要重新部署游戏服务。
- Web、Windows、Android 和 HarmonyOS 客户端需要从 `v0.1.1` 源码重新构建。
- Android 与 HarmonyOS 应在目标真机上重点验证横屏两个方向的挖孔避让、发两次摊牌和牌桌图层显示。
