# 好友德州 1.0.0 更新说明

所有平台均需更新（Web 端刷新即可）。

## AI 复盘更好用了

- 回放停在你自己操作过的某一步时打开「AI 复盘」，会直接滚到这一步的点评并高亮，不用从头翻。
- 分析过的牌局会一直保存，下次打开回放直接能看，不用重新分析。
- 点了分析之后可以放心离开：回大厅、去打牌、关掉客户端都不会打断，下次打开那手回放就能看到结果。
- 大模型服务繁忙时会自动重试，面板上会写明正在重试第几次；实在不行会告诉你原因，稍后可以重新分析，失败的不占次数。
- 复盘面板去掉了开头的「牌局概况」，其余内容不变。
- 管理员可以给每个人单独设每天能分析几手、同时能分析几手。
- 手机上的牌局回放：两侧的说明和按钮跟牌桌一样大小比例，不再显得突兀，左上角的标题也能完整显示了。

## 规则修正

- 对手都已全下时，你只能跟注或弃牌，不再出现加注按钮（以前加上去的筹码没人能跟，最后会原样退回，筹码结算一直是对的）。
