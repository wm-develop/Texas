# 阶段 2：可玩 MVP 清单

> 历史完成记录。阶段 3 账户筹码、管理、生产持久化和后续牌桌社交能力不在本清单中，见[项目现状](PROJECT_STATUS.md)。

目标：完成注册账号、好友房、2～10 人真实联机牌局、聊天、语音、断线恢复和最近牌局；10 台客户端连续完成至少 100 手，无状态不一致。

## 纵向链路 1：账号与好友房

- [x] 注册账号和密码安全散列。
- [x] 登录和短期访问令牌。
- [x] 当前用户接口。
- [x] 创建带预设和可选密码的好友房。
- [x] 通过房间码加入好友房。
- [x] 2～10 人座位和准备状态。
- [x] 房主离开后的自动移交、最后一人离开后的房间关闭和成员权限。
- [x] 为账号、会话和房间定义可替换仓储接口。

## 纵向链路 2：真实牌桌连接

- [x] WebSocket 会话鉴权。
- [x] 加入牌桌并发送接收者裁剪后的快照。
- [x] 准备和开始下一手。
- [x] 将动作请求接入阶段 1 权威状态机。
- [x] 广播公共事件，底牌仅发送给本人。
- [x] 请求幂等、事件序号和断线补发；涉及私人快照的缺口安全回退为完整快照。
- [x] 无法补发时发送完整快照。
- [x] 牌局结算以手牌 ID 幂等写入历史和追加式账本仓储。

## 纵向链路 3：聊天与语音

- [x] 真实牌桌文字消息广播和历史恢复。
- [x] 快捷语和表情。
- [x] 本地玩家屏蔽同时过滤文字和静音语音；服务端禁言状态强制拦截发送。
- [x] TRTC UserSig 使用真实会话和牌桌成员权限。
- [x] 客户端显示语音成员、开麦状态和说话状态。
- [x] 牌局、文字和语音故障保持隔离。

## Flutter 客户端

- [x] 注册和登录页。
- [x] 大厅、创建房间和输入房间码。
- [x] 等待区、座位和准备状态。
- [x] 真实牌桌快照、底牌、公共牌和筹码。
- [x] 合法动作按钮、加注金额和服务端倒计时。
- [x] 结算和下一手。
- [x] 断线重连与恢复提示。
- [x] 最近牌局及展开详情；只显示本人底牌和摊牌公开底牌。
- [x] 行动/结算提示音、公共牌/底池/行动位过渡动画、语音音量、自动加入语音和本地持久化设置。
- [x] Web、Windows、Android、HarmonyOS 构建及自动化核心流程冒烟测试。

## 阶段退出验收

- [x] 10 个独立 WebSocket 客户端加入同一好友房并保持各自鉴权会话。
- [x] 10 客户端连续完成 100 手协议级联机牌局。
- [x] 三设备牌局、文字聊天和双向语音同时运行已实机验证。
- [x] 重复动作和重复加时请求不重复扣筹码或消耗加时卡。
- [x] 断线后恢复相同 `handId`、最新快照和本人原有底牌。
- [x] 100 手测试全程无状态不一致，且每手账本和最终筹码均守恒。
